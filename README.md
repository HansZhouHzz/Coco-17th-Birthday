# Coco's 17th Birthday

一个为 Coco 制作的互动生日祝福网页。

## 项目结构

```text
index.html                  # 网页入口
assets/
  audio/
    happy-birthday.mp3      # 许愿时播放的背景音乐
```

## 本地预览

直接用浏览器打开 `index.html` 即可。

## GitHub Pages 发布

1. 在 GitHub 新建仓库，例如 `coco-17th-birthday`。
2. 上传本项目的 `index.html` 和 `assets` 文件夹。
3. 在仓库 Settings → Pages 中，选择从 `main` 分支的根目录部署。
4. 保存后，GitHub 会显示公开访问网址。

> 生日网页会公开展示在该网址上；请仅在确认可以公开后启用 GitHub Pages。
